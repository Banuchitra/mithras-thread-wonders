The roadmap

Every step follows the same loop: learn page → plan mode → build → review → PR → journal note.

  1. 0

    Setup

    Personal GitHub, repo, CLAUDE.md, hooks, subagents, custom commands. Learning hub (this site).
  2. 1

    Inception

    Intent, requirements and user stories. You decide the brand, UI design and colours here. The work is split into units. Gate: you approve the docs.
  3. 2

    Construction

    U1 scaffold + CI → U2 domain + content (TDD) → U3 catalog UI → U4 Pages CMS → U5 polish/SEO/a11y. One PR per unit.
  4. 3

    Operations

    Auto-deploy to GitHub Pages, Lighthouse checks, a "How to add a product" guide for your cousin.
  5. v2

    In-browser AI chatbot

    WebLLM model running in the visitor's browser, grounded in product data. No server, no keys, $0.
  6. ☁

    Later: AWS phase

    Swap the content adapter for an AWS backend as you progress through DVA-C02.
